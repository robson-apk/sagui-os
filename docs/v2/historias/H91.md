# H91. Utilitários de texto no estilo Unix

**Fase:** versão 2.1 (comunidade)

## Objetivo

Trazer para o SaguiOS os utilitários de texto clássicos do fork
SaguiOS-Extended, do Alejandro Anuncibay, reescritos sobre a libsagui atual
(a do fork é outra, bem maior). Cada um tem o nome Unix e um apelido em
português no `sagsh`:

| Nome | Apelido | O que faz |
|------|---------|-----------|
| head | inicio | o começo do texto |
| tail | fim | o fim do texto (e `-f`) |
| sort | ordenar | ordena linhas |
| uniq | unicos | junta linhas repetidas |
| cut | cortar | campos e colunas |
| tr | trocar | troca, apaga e junta letras |
| seq | sequencia | sequências de números |
| rev | inverter | cada linha ao contrário |
| tac | de-tras | as linhas na ordem inversa |
| nl | numerar | numera linhas |
| diff | diferencas | compara arquivos (clássico e `-u`) |
| find | procurar-arquivo | acha arquivos pelo nome, tipo e tamanho |
| sed | editar-fluxo | edita o texto que passa (`s///g`, `d`, `p`...) |
| tree | arvore | árvore de pastas |
| cal | calendario | calendário |
| bc | calcular | calculadora de muitos dígitos |
| expr | expressao | expressões na linha de comando |
| base64 | | RFC 4648 |
| md5sum | md5 | RFC 1321 |
| od | octal | bytes em números |
| xxd | hexa | bytes em hexadecimal, e a volta (`-r`) |

Todos leem arquivos ou a entrada (`ls bin | sort -r | head -3`), têm
mensagens em português e códigos de saída. O `sagsh` passou a aceitar aspas
simples (`sed 's/a/b/'`).

## Critério de aceite

`tests/h91_utilitarios.py`: cada programa com entradas conhecidas num
pendrive, pipes e apelidos; `h16_shell.py`, `h24_terminal_janela.py` e
`h83_pequenos.py` continuam passando.

## Resultado

Feito, em quatro partes. Na libsagui entraram quatro ajudas pequenas
(`abrir_para_ler`, `ler_ate_o_fim`, `converter_numero`, `minuscula_latin1`);
o motor de expressões regulares do `sed` e do `expr` fica em
`userland/programas/expressao_simples.h`. Ficaram de fora, por ora: `sed -i`,
grupos `\( \)` nas expressões, `find -exec` e as funções e laços do `bc`.
