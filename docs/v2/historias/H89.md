# H89. Sagui Code numa janela

**Fase:** 11 (versão 2.1)

## Objetivo

O núcleo do Sagui Code separado da interface (`agente.c`), o Terminal
funcionando como antes e uma janela parecida com um aplicativo de agente de
programação: sessões à esquerda (guardadas no pendrive), a conversa com um
bloco para cada ferramenta, a caixa do pedido com Enviar e Parar, e em cima o
modelo, o gasto e um botão para abrir a pasta do projeto no Arquivos.

## Critério de aceite

um pedido com ferramenta aparece na janela e é guardado; trocar de sessão traz
o histórico de volta; renomear e apagar pelo menu; os testes do Terminal
(H69 a H72) continuam passando.

## Resultado

`userland/saguicode/agente.c` (núcleo), `saguicode.c` (Terminal) e
`janela.c` (`/bin/saguicode-janela`). No menu do sagui: "Sagui Code" (janela)
e "Sagui Code (terminal)"; ícone na doca. Teste `h89_saguicode_janela`
(capturas H89-1-sessao e H89-2-ferramenta); decisão D050.
